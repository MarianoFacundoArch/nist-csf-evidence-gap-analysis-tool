# NIST CSF 2.0 — Crosswalks to Other Frameworks (Informative References)

> **How to read this report**
>
> - **Related, not equivalent.** A mapping records that a CSF 2.0 outcome and a reference in another framework are related. It does not say that achieving one satisfies the other.
> - **Coverage is about the CSF outcome only.** The coverage shown beside an outcome is what this assessment found for that outcome. It is not a determination of conformance with the referenced control or requirement, and this report does not measure conformance with any other framework.
> - **Three levels of relationship.** A mapping relates a reference to one CSF outcome (a Subcategory), to a whole Category, or to a whole Function. Each crosswalk below lists the first kind in one table and the other two in a second table. For a whole Category or Function the report shows how the outcomes under it are distributed across coverage levels; it does not pick one, because the mapping does not.
> - **Identifiers only.** No control or requirement text from the referenced frameworks is reproduced here. Consult each framework's own publication for what an identifier means.
> - **Who made each mapping.** The mappings come from: NIST National Online Informative References (OLIR) Program, via the NIST CSF 2.0 reference data service. Each was developed by the party named as its developer there — not by this project, which adds no mappings of its own. Inclusion here is not an endorsement by NIST or by this project.
